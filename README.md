🛒 E-Commerce App with Admin Panel

A full-stack E-Commerce web application with a dedicated Admin Dashboard that allows product management, order tracking, secure authentication, and real-time payments using Razorpay. Built with the MERN stack and deployed on Vercel and Render.

🔗 Live Demo: https://ecommerce-app-frontend-mauve.vercel.app/


🚀 Features
👤 User Features

User authentication & authorization using JWT

Browse products with dynamic data and exact category/type filtering

Select product sizes before adding to cart

Add/remove products from cart

Secure checkout with Razorpay UPI payments

Real-time order processing

🛠️ Admin Features

Separate Admin Dashboard

Add, update, and delete products

View and manage customer orders

Secure admin-only access

Easily accessible via quick-link button in the frontend navigation

Manage multi-user data efficiently
